# Sudoku Game

A small browser-based Sudoku game built with HTML, CSS, and JavaScript.

## Features

- 9x9 Sudoku board
- Difficulty selector: Easy, Medium, Hard
- Keyboard and on-screen number pad
- Cell validation and conflict highlighting
- Timer and reset controls
- "Solve" and "Check" actions

## Run locally

Open `index.html` directly in the browser, or serve it locally:

```bash
cd sudoku-game
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – game layout
- `style.css` – board and UI styling
- `script.js` – game logic and generation
